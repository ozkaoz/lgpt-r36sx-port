# Release Notes — U2.50 FINAL

## Status

Stable checkpoint approved after SD testing.

## Highlights

- Final Mixer layout refinement.
- Master meters moved and resized.
- Mixer tempo editing with visual feedback.
- Track pan display improved.
- U2.46 Phrase workflow retained as stable.
- U2.41 WAV export workflow retained as stable.

## Mixer

- Help text moved to the upper area.
- Mixer/fader area moved downward.
- Larger channel bars for better readability.
- Channel bars are stable fader-style indicators rather than constantly flickering peak meters.
- Master L/R remains the dynamic part of the Mixer display.
- Pan is shown clearly with `Lxx`, `C`, `Rxx` and directional markers.
- Tempo changes via `Y + arrows` retain a clear visual highlight.

## Project/Master

- Master L/R meters are vertical.
- Meters are longer and positioned lower-left, away from the text fields.

## Commands/FX

- `FBYP` removed from visible command selector.
- Legacy command compatibility remains internal.

## Compatibility

Old projects remain loadable. Projects saved from newer versions may include newer blocks such as Phrase step volume data.

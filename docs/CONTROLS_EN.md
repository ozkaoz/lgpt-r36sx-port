# Main controls

- Chopper Undo: `L1+X`.
- Chopper Redo: `R1+X`.
- Rename a sample in the browser: `L1+X`.
- Delete a sample in the browser: `L1+Y`, confirm with `A`, cancel with `B`.
- Name editor: left/right moves the caret; up/down changes the character; `X+up/down` jumps five characters; `L1+X` toggles case; `A` confirms; `B` deletes.
- Record: Preview, Save and Discard operate on a pending temporary take.

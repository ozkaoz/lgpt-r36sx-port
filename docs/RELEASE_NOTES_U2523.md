# LGPT R36SX U2.52.3

Stable R36SX port with TreeFrogUI integration, bidirectional USB-C OTG audio, transactional recording, safe sample management, Chopper Undo/Redo and consolidated bilingual documentation.

The binary release includes the compiled core, USB Audio daemon, UAC2 module, launcher, OTG scripts, installer, verifier and SHA-256 checksums. TreeFrogUI is required and is not redistributed.

# Controles principales

- Chopper Undo: `L1+X`.
- Chopper Redo: `R1+X`.
- Renombrar sample en navegador: `L1+X`.
- Eliminar sample en navegador: `L1+Y`, confirmar con `A`, cancelar con `B`.
- Editor de nombre: izquierda/derecha mueve el cursor; arriba/abajo cambia carácter; `X+arriba/abajo` salta cinco caracteres; `L1+X` cambia mayúsculas/minúsculas; `A` confirma; `B` borra.
- Record: Preview, Save y Discard actúan sobre una toma temporal pendiente.

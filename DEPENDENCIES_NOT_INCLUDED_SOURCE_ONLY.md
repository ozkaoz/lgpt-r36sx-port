# Dependencias no incluidas en este paquete source-only

Este zip es intencionalmente fuente/documentación/scripts para GitHub. No incluye binarios ni librerías compiladas:

- `*.a`
- `*.so`, `*.so.*`
- `*.dll`, `*.dll.a`
- builds, releases, zips, RAR, logs

Si se requiere reproducir exactamente el entorno de compilación original, usar la toolchain local indicada en la documentación del proyecto y restaurar dependencias del entorno de desarrollo, no desde backups de SD.

# Notas U2.46 FINAL

U2.46 FINAL es la versión aprobada después de probar U2.46 TEST en SD.

Esta versión no cambia DSP/FX ni Master. Su función es congelar como estable el flujo de Phrase y navegación antes de continuar con commands, efectos y visualización del Master.

## Control map final de Phrase

```text
Y = preview current row
L1+X = start selection
X = cut active selection
L2+LEFT = previous used phrase
L2+RIGHT = next used phrase
L2+UP = previous phrase assignment in current Song channel
L2+DOWN = next phrase assignment in current Song channel / create-link new phrase if needed
double A = open Pitch/Envelope for assigned chop
R1+B = back to Phrase when Pitch/Envelope was opened from Phrase
```
